---
name: Take Order palette system
description: The shared visual language for seller and buyer surfaces.
---

Use Paper White (#FFFFFF) for the workspace and cards, pure black (#000000) for primary interface text and action surfaces, and pure white (#FFFFFF) for text or icons placed on filled black surfaces. Use Receipt Beige (#E8DCCF) only for an explicitly receipt-like outer surface.

**Why:** The user explicitly chose pure black over the previous secondary blue-gray tone and required white contrast on black backgrounds.

**How to apply:** Prefer the CSS theme variables and shared Button/StatusPill styles. Keep the workspace light, use pure black for primary actions and selected states, use pure white on filled black surfaces, and retain the warm/cool chart palette for bars, charts, platform marks, and other contextual visuals.
