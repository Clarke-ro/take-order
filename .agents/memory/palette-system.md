---
name: Take Order palette system
description: The shared visual language for seller and buyer surfaces.
---

Use Paper White (#FFFFFF), a soft cool-gray workspace, and deep blue-gray primary actions instead of pure black surfaces. Use Receipt Beige (#E8DCCF) only for an explicitly receipt-like outer surface.

**Why:** The supplied reference uses a light operational dashboard with white navigation, pale gray canvas, white cards, and a dark blue-gray action color. Pure black made the interface feel harsher than the intended product direction.

**How to apply:** Prefer the CSS theme variables and shared Button/StatusPill styles. Keep the workspace cool and light, use deep blue-gray for primary actions and selected states, and use the warm/cool chart palette for bars, charts, platform marks, and other contextual visuals rather than forcing them to monochrome.
