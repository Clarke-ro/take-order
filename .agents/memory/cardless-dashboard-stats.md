name: Cardless dashboard stats
description: The preferred presentation for performance metrics and bar-based dashboard insights.
---

Use open white sections for performance metrics instead of enclosing every stat group in a bordered card. Present comparisons with light horizontal tracks, a single consistent fill color, and right-aligned values or percentages.

**Why:** The supplied mobile Insights reference makes the comparison readable through spacing, track length, and aligned percentages rather than nested surfaces or multiple colors.

**How to apply:** Keep section headings and stat rows visually separated by whitespace. Use color sparingly; for the seller dashboard, prefer the shared monochrome black fill and light neutral track.
