---
name: Take Order typography system
description: The shared typeface choice for seller and buyer UI.
---

Use Inter for body copy and display headings to match the supplied reference image. Keep IBM Plex Mono for compact utility labels, tracking labels, and tabular metadata.

**Why:** The reference uses a neutral grotesk with tight, heavy headings; the previous Manrope and Space Grotesk pairing felt more rounded and decorative than the desired direction.

**How to apply:** Change the shared font variables rather than styling individual screens. Load the heading weights used by the app so bold display text does not fall back to synthetic weights.
