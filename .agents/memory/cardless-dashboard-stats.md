name: Cardless dashboard stats
description: The preferred presentation for performance metrics and bar-based dashboard insights.
---

Use open white sections for product and channel performance comparisons instead of enclosing every ranking row in a bordered card. Present comparisons with light horizontal tracks, a consistent monochrome fill, and right-aligned values or percentages. Keep the high-level Overview summary in Duka's established branded metric-card layout.

**Why:** The user rejected the reference-inspired summary treatment and prefers Duka's existing card language, while still keeping ranked comparisons open and easy to scan.

**How to apply:** Keep Overview headline metrics in the existing bordered cards. Keep product/channel rankings open and compact, with only the tracked name, bar, and end statistic where possible. Keep interface text and fills on the shared black-and-white system with a light neutral track.
