---
name: Metric indicator rules
description: How Take Order stat cards should use percentage badges and indicators.
---

Use a percentage badge with an up/down arrow only when the card has a meaningful, data-backed ratio. If it does not, omit the indicator entirely rather than showing a descriptive status or an invented percentage.

**Why:** The user prefers metric cards to communicate values directly and does not want text labels or meaningless 0%/100% indicators competing with the main value.

**How to apply:** Derive percentages from real denominators such as revenue, views, orders, inventory items, or clients. Keep explanatory context in the card note when useful, but do not turn status text into a badge.
