name: Cardless dashboard stats
description: The preferred presentation for performance metrics and bar-based dashboard insights.
---

Use open white sections for performance metrics instead of enclosing every stat group in a bordered card. Present comparisons with light horizontal tracks, one consistent restrained accent fill, and right-aligned values or percentages.

**Why:** The supplied mobile Insights reference makes the comparison readable through spacing, track length, and aligned percentages rather than nested surfaces or multiple competing colors.

**How to apply:** Keep section headings and stat rows visually separated by compact spacing. Strip each ranking to the item name, track, and end statistic when possible. Keep interface text black and use one shared accent fill with a light neutral track.
