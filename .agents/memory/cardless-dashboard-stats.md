---
name: Cardless dashboard stats
description: The preferred presentation for performance metrics and bar-based dashboard insights.
---

Use open white sections for product and channel performance comparisons instead of enclosing every ranking row in a bordered card. Present comparisons with light horizontal tracks, one consistent restrained accent fill, and right-aligned values or percentages. Keep the high-level Overview summary separate: it uses a compact two-tier grid of branded cards.

**Why:** The supplied mobile Insights reference uses two distinct patterns: compact cards for headline metrics and simple tracks for ranked comparisons. Mixing all metrics into one card treatment makes the dashboard harder to scan.

**How to apply:** Use four primary Overview cards with a period label, headline value, short detail, and small trend graphic. Follow them with four compact secondary transaction cards. Keep product/channel rankings open and compact, with only the tracked name, bar, and end statistic where possible. Keep interface text black and use one shared accent fill with a light neutral track.
